LANDING PAGE - SISTEM SARAF
===========================

Isi folder:
- index.html     : struktur landing page
- styles.css     : seluruh styling responsive + animasi
- script.js      : interaksi menu, tab, stepper sinapsis, scroll progress, dan kuis
- assets/        : gambar materi yang diambil dari PDF sumber

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html langsung di browser.
3. Jika ingin dijalankan seperti website lokal, jalankan folder ini dengan Live Server / localhost.

Tampilan:
- Warna dasar hijau + kuning.
- Responsive desktop, tablet, dan mobile.
- Tanpa framework dan tanpa dependency eksternal.
- Bisa diedit menggunakan VS Code.

Materi bersumber dari PDF presentasi Sistem Saraf Kelompok 5 yang diberikan pengguna.
